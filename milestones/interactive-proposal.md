## Description

From my static visualization, I was surprised by the cumulative emissions generated by multifamily housing and offices compared to larger buildings. I want to ground the user in this comparison and show that housing and offices - the buildings that we interact with most on a daily basis - use the most cumulative emissions, though data centers and other large buildings are still energy intensive, using an interactive that has the user guess differences in cumulative emissions of different building types in Chicago.

Because this is Chicago-based, one way to center the narrative around a Chicago user would be to let users search how much energy certain buildings use.

Finally, I'd also like an interactive component that allows users to simulate different policy and investment scenarios to see if Chicago can reach its 2040 clean energy goal. This would include different levels of household changes in energy use as well as different ratios of government spending on cleaning the grid's energy sources. The user can drag sliders to change different factors related to building energy use and source to see a forecast of 2040 emissions. I would add some preset simulation buttons such as "what happens using the current trend".
